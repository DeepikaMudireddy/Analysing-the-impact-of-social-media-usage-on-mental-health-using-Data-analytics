# Social Media Usage & Mental Health Dashboard

## Overview
This Power BI dashboard analyzes the relationship between social media usage and mental health indicators such as depression, worry, and sleep.

## Features
- KPI Cards (Average Worry, Sleep, Depression)
- Distribution of Worry Scores
- Distribution of Depression Scores
- Comparison of Social Media Platforms
- Social Comparison vs Depression Analysis

## Tools Used
- Power BI
- Power Query
- DAX
- CSV Dataset

## Key Insights
- TikTok users reported the highest average depression and worry scores.
- Increased daily social media usage is associated with higher depression scores.
- Higher social comparison frequency is linked with increased worry and depression.
